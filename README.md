# Matrix 3D Lab UG: quote page

Public page where customers upload a 3D model, choose material and options,
see an instant price estimate, and send a quote request to Matrix 3D Lab UG.

Hosted with GitHub Pages. The source lives in the private Matrix One app
repository (`quote-page/`); this repository only serves it. It contains no
secrets: the page gets its connection from the link the Matrix One app gives
out.
